# 兒童青少年身心健康導航

依 AACAP、AAP 與 NICE 兒少適用建議設計，提供臨床使用者安全分流、診斷方向核對、治療討論與追蹤。版本 1.1，內容查核 2026-11-13。

## 操作流程

1. 填寫 2–17 歲年齡、症狀持續週數、功能影響及多方資訊。
2. 逐項直接詢問安全。未知不視為陰性；急性風險暫停一般治療路徑。
3. 完成診斷核對與鑑別，記錄躁期、身體／藥物因素、現有 SSRI 及共同目標。核對不是正式診斷，需完整臨床評估。
4. 依年齡、時間、功能、資訊完整度及診斷狀態提出下一步，包含心理、家庭、學校介入與適當藥物討論。
5. 輸入每次追蹤的量表總分、填答者、功能、安全、副作用及下次日期，觀察同工具同填答者變化。

## 九個方向

| 方向 | 照護核心 |
| --- | --- |
| ADHD | 跨情境、持續時間、症狀數；學齡前行為介入優先，生長及心血管監測 |
| 焦慮／拒學 | 釐清類型，CBT／暴露、家庭與返校合作，必要時 SSRI |
| 憂鬱 | 兒少易怒、躁期鑑別；心理治療與適齡 fluoxetine 討論 |
| OCD | 家庭參與 CBT／ERP，依年齡及足療程反應討論加藥 |
| 自閉症 | 多專業發展評估與支持；無核心特徵常規藥物 |
| PTSD | 安全與創傷焦點治療，不套用成人藥物路徑 |
| 飲食疾患 | 身體穩定、電解質、生長與變化速率，不只看 BMI |
| 疑似雙相 | 專科縱向診斷，避免以易怒單獨診斷及抗憂鬱藥單方 |
| 精神病症狀 | 身體／物質鑑別、早期專科及藥物監測 |

## 教學模組（v1.1 新增）

- **示範病例 14 例**：原 8 例入門＋6 例進階（憂鬱合併自傷與霸凌、ADHD 合併抽動、SSRI 後躁化、ARFID、大麻相關精神病症狀、目睹家暴兒童）。進階病例含 3 組問答，載入後直接顯示引擎判斷；實際臨床仍須逐項重新詢問。
- **臨床測驗 20 題**：基礎 10、高階 10，選項隨機排列，作答即顯示解析與指引連結。
- **心智圖**：12 分支、53 重點，可搜尋，並有「回憶模式」先遮住重點自我測試。
- 網址可用 `#cases`、`#quiz`、`#map` 直接開啟分頁。

另附可收合診療路徑。

## v1.1 修正

- 焦慮少於 4 週、創傷後少於約 1 個月改為「補評估」，不直接進入治療計畫。
- OCD／自閉症／PTSD 的治療層級不再重複心理介入全文，改為分齡重點。
- 示範病例載入時帶入功能與資訊來源，而不只年齡與主題。
- 連續提示訊息不再被前一則的計時器提前關閉。
- 新增深色模式、導覽 `aria-current`、網址分頁。

## 追蹤與隱私

- 純 HTML、CSS、JavaScript，無遠端個案資料庫、分析追蹤或外部腳本。
- 預設資料只在當次頁面記憶中，重整會遺失。手動「儲存在此裝置」才寫入 localStorage，鍵為 `qinghe-youth-v1`。不自動讀取舊個案。
- 僅管理目前一案。載入示範或開始新案前先匯出；JSON 可保留目前評估及全部追蹤，但不提供跨裝置同步或 JSON 匯入。
- 不輸入姓名、病歷號、聯絡方式。共用電腦不建議保存；匯出檔仍可能含敏感健康資訊，請妥善保管。
- SCARED 41 題（0–82）、ADHD-RS 18 題（0–54）、PHQ-A（0–27）、CY-BOCS（0–40）只接受合法取得、適齡版本的總分，未內建量表原文。
- 不混比不同工具或填答者。自訂困擾與功能 0–10 非驗證量表，僅供同案描述追蹤。
- 預設下次 7 日為工具照護提示，須團隊確認；無背景通知。追蹤警訊不因量表改善而排除。

## 臨床限制與來源

不取代完整會談、身體檢查或專科診斷，不是自動處方。功能下拉選單不等同疾病嚴重度。藥物須依年齡、體重、共病、交互作用及所在地仿單個別決定。國外指引不能代表台灣核准適應症或健保條件；網站未自動判定給付。

來源完整連結在網站「指引來源」與 `clinical.js`：AACAP 指引索引／焦慮 CPG 2020、AAP ADHD 2019、NICE NG87／NG134／CG31／CG170／NG116／NG69／CG185／CG155，以及 NIMH 診斷概念教育資料。

AACAP 索引同時含現行 CPG 與較早 Practice Parameters，各文件版本、年齡及診斷系統不同，未宣稱全部為 2026 新版。部分早期／4–12 週追蹤節點屬工具提示，依風險與療程調整。

任何自傷／自殺計畫、無法維持安全或身體不穩定，優先急診／緊急專業評估。分數不能排除危險。

## 維護與部署

`index.html`、`style.css`、`clinical.js`、`app.js` 放同一目錄；無建置需求。GitHub Pages 可用 main 分支根目錄。公開網站前需確認對應公開範圍。

執行 `node verify.cjs`（或無 Node 的 macOS：`/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc verify.cjs`）檢查 52 項：安全、年齡、診斷完整度、躁期、身體因素、各診斷持續時間、分齡治療、每個示範病例的預期結果、測驗與心智圖結構。更新臨床內容時應同步複核原始指引與瀏覽器流程。
